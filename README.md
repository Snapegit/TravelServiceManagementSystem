

## 🌟 项目简介

这是一个基于 **Node.js + Express + Vue3 + Vue3 + MySQL** 构建的旅游服务管理系统。

### 🧩 功能模块一览

- **用户端**：登录注册 / 首页 / 景点信息浏览与评论 / 景点分类筛选 / 旅游路线浏览与评论 / 门票在线购买 / 特产中心 / 我的收藏 / 个人中心
- **管理端**：轮播图管理 / 系统用户管理 / 旅游攻略管理 / 特产中心管理 / 景点信息管理 / 旅游路线管理 / 评论管理 / 我的收藏管理
